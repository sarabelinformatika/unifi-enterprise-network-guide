# Limitations

- UniFi capabilities and UI paths vary by gateway, console, Network version, firmware, region, and license/service.
- Examples are not a substitute for RF survey, cable certification, security review, or change approval.
- The scripts do not authenticate, modify configuration, or prove end-to-end application availability.
- Port lists are intentionally conservative and must be checked against current vendor documentation.
- Undocumented APIs and shell modifications are outside the supported baseline.
- A lab result does not prove client compatibility or production capacity.
