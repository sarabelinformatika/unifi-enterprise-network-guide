# Supported versions

The guide targets currently supported UniFi Network releases and modern UniFi gateways, switches, and access points. UI labels and capability vary by model, console, firmware, region, and release channel.

| Guide release | Status | Notes |
|---|---|---|
| 1.x | Supported | Review against current Ubiquiti release notes before implementation |

Legacy controllers, first-generation CloudKeys, end-of-life devices, and undocumented APIs require separate risk acceptance and migration planning.
